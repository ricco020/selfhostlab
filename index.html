How we test

Test server: Contabo Cloud VPS, 8 AMD EPYC vCPU, 23 GB RAM, Ubuntu, Node.js 22. Each app runs in a throwaway folder, is measured with ps sampled every 0.3 s, then removed. We state the limits of every test (install method, database, number of workflows) next to the numbers.
